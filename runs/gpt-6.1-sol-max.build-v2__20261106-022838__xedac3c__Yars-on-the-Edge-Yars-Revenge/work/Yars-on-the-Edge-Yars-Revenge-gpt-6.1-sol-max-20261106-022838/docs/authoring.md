# Author another siege

Pause → Dev workbench → Shield layout editor. Altered runs and all editor previews are practice. These tools are disabled in live Hub sessions; diagnostics remain available.

The cell column and row sliders select a cursor with a controller. Choose CELL or DIAMOND, then Paint or Erase. A pointer paints directly; right click or Shift erases. The plate travel/period and refuge position/width controls edit actual simulation data. Play edited encounter starts the selected sector using that data. Save/Load preset uses local storage. JSON import/export offers copyable text and a downloadable JSON file, including when the game runs from file://.

The schema is `1`. An encounter contains:

- `name`: at most 40 characters; `sector`: 0, 1 or 2, determining the fortress rule set.
- `refuge: {x, w}`: x 90–350, width 24–100. This strip suppresses both weapons while active.
- `plates`: one or two `{amplitude, period, phase}` objects. Amplitude is at most 48 world units; period is 3–30 seconds; phase is radians. Cells retain identity as their plate moves. Offset is `sin(sectorTime * 2π / period + phase) * amplitude`.
- `cells`: at most 400 unique `{x, y, material, plate}` entries. x 330–522; y 20–260. Material 0 is normal, 1 reflects a siege shot once. Plate is an index into the paths. IDs are regenerated by validation.

Keep a cannon lane at least 20 units wide between live cell centers (a standard missing row leaves 24 units between adjacent cell centers). The physical projectile has radius 4 and cells have an effective collision radius of 6. The editor permits difficult layouts, but every encounter keeps the renewable dock refill and repeatable Swirl flight.

`../src/content/sectors.js` contains the three completed campaign encounters. `docs/encounter-example.json` is a completed fourth practice encounter. It has two shifting plates and a deliberate horizontal breach, with reflective teeth away from that breach. Import it from the JSON screen and play.

Live Balance exposes scout speed, bite interval, charge threshold, primary cadence, cannon speed/warning, pursuer speed/turn, Swirl speed/warning, outage duration and reserves. Values are clamped and applied on a fixed simulation boundary. Reset to Defaults restores the original values. Freeze is independent of the input/UI clock; Step one tick works while frozen or paused. Phase jumps, preview Swirl, seed editing and encounter restart are available in the same workbench.
