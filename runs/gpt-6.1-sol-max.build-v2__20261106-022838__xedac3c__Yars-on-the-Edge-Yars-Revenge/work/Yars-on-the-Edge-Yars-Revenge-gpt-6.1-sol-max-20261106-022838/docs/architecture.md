# System boundaries

`src/sim/world.js` is the sole authoritative world. It is independent of DOM, canvas, sound, wall clock and menu focus. Its step is exactly 1/120 second. It stores tick, seed state, stable IDs, occupancy, moving plate transforms, fortress state, players, reserve, shots, hunters, chain, score breakdown, lessons and confirmed event IDs. Snapshot and hash are read-only.

The fortress state machine is dock → windup → committed flight → return → dock. Core hits enter a guarded phase break or collapse. Phase epochs make overlapping siege hits idempotent. The last phase ignores docked damage and always returns to a contact-safe renewable refill posture. Death reserves are paid immediately once, and paid respawns keep a team alive until they arrive. Clear and ending awards are guarded by phase/outcome.

Input adapters produce `{mx,my,ax,ay,fire,cannon}`. Vectors are normalized in the simulation. `cannon` is a monotonically increasing edge ID, not a held button. The host validates all actions, including its own, and the world independently checks live player, charge, refuge and deduplication. Practice/dev commands travel separately and are disabled for embedded rounds.

`src/presentation/` consumes snapshots and event IDs. Native `E.px`, `E.tones`, depth-sorted `r.actor`, shape materials, shadows and local lights build the image. Custom rigs use update/draw posing for wings, banking, legs, mandibles and thorax; the core changes anatomy with simulation state. Cosmetic RNG is seeded separately from combat and drawing never consumes combat RNG. Audio shares the engine’s settings buses; every custom source has a finite envelope and stop time.

The original SHOOTER kit’s overhead coordinate system and scene/actor pipeline are the foundation. The unrelated catalogue, humanoids and stock gameplay were removed. Native `E.Shell` supplies menu focus/back/hover, pause, settings, rebinding and fullscreen. Custom screens and styles extend it. Developer settings are kept off the ordinary settings screen.

`src/online/session.js` registers lifecycle handlers before connection. Negative and pre-start Hub clocks do not advance the world. A host timer targets the Hub clock independently of rendering. Only the host advances the world or finishes. Reliable cumulative siege edges are repeated at the input cadence until snapshots acknowledge them. Snapshot sequences reject stale delivery and include a full occupancy mask, so loss cannot resurrect cells. Client prediction changes only a presentation copy; damage is always host-confirmed.

Tests use the native engine VM harness and real packaged HTML. Verbose traces and generated visual evidence live under tests/artifacts. The optional extra harness is an instrumented copy generated by the test suite; the official files in vendor/hub remain unchanged.
