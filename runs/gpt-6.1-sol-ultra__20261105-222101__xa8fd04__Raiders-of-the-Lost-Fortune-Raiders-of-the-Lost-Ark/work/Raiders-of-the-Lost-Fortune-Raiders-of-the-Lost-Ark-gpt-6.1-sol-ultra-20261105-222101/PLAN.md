# Raiders of the Lost Fortune

Original comic action-adventure inspired by Raiders of the Lost Ark (1982). Title selected by Python secrets.randbelow from fifty privately brainstormed candidates.

One continuous, authored temple: courtyard combat and optional caches; telegraphed spike traps and a whip grapple; three rotating sign puzzle with a visible inscription; relic retrieval; boulder escape back to camp. Solo or two-player shared-world co-op. A host owns physics, enemies and mission state. Both explorers have the same capabilities.

Three.js r180 WebGPURenderer, Rapier 0.19.3 capsule collision, native AnimationMixer clips, procedural geometry and ink silhouette outlines. Web Audio only. Standard mapping gamepad, mouse/keyboard and invisible touch sticks. Controller focus menus, settings, pause, live developer tuning, checkpoints, terminal results, credits and looping attract replay.

Build: node build.mjs. Validate: run tests/check.sh. Ship one HTML in the parent directory, plus exit-interview.json. External runtime dependencies are permitted. No internet research; only the requested AI Hub implementation and library downloads.
