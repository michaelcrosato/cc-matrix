# Shared implementation contracts

Browser bundle preserves ES module scopes. Full pinned engine runs first; My3D2dge is a global. Files use ordinary named ES exports/imports. No asset fetch at runtime.

Simulation: src/sim/world.js exports World. `new World({level=0,players=1,seed=...,demo=false,custom=null})`; `.step(dt, commands)` where commands is `{[actorId]: {dir: [dx,dy] or null,plant: boolean,actionId?:string}}`. Fixed 1/120 step; all time in seconds/cells, 16 world units per cell. `.s` holds serializable team state. `.graph` MazeGraph. `.events` drained by presentation per step with `{type,x,y,value?,actor?,...}`. `.snapshot()` and `.restore(data)` restore checkpoint/replay/host. `.view()` lightweight render snapshot. `.nextGarden()`, `.retry()`, `.tune(key,value)` and `.dev(action,arg)` for standalone only (network adapter must refuse).

Render view: `{level,garden: levelData, t,phase,score,lives,seeds,fright,combo,comboLeft,remaining,modified,demo,players:[{id,x,y,dir,invuln,respawn,bite,plant}], crawlers:[{id,x,y,dir,segments,mode,chew,warning,body:[{x,y,tail:boolean,index}]}], sentries:[{id,x,y,dir,spin,fright}], bait:[{owner,x,y}],trees:[[x,y]], stats:{bites,catches,trees}, notice,noticeLeft}`. Coordinates cells (centres indexed integer). Actors get native rigs in renderer, no DOM. Hero blue, partner coral. Head green with danger mouth; body green; final tail warm golden fruit with leaf and bright diamond mark. Sentries moth and beetle distinct. Colors readable by silhouette.

Audio: module src/audio/music.js exports `GardenAudio(game)` with methods `scene(kind,garden=0)`, `event(event)`, `update(dt,view)`, `stop()`, `resume()`, `dispose()`, `diagnostics()`. Use native game.audio synthesis/music and three buses; no audio files; music fresh profile 0.1 via app settings. kind title/play/clear/defeat/victory/workshop/attract. Pausing uses stop/resume without duplicate loops. Expose offline validation helper if useful. Module can import content DEFAULTS/THEMES/TITLE. No edits elsewhere except own artifacts/audio-notes.md.

Native art: src/view/rigs.js exports `GardenRigs(game)` methods `update(dt,view)`, `drawActor(r,kind,actor,opts={})`, `tree(r,x,y,theme,t)`, `sprout(r,x,y,theme,t)`, `wrap(r,x,y,dir,label,theme,t)`, `spectator(r,x,y,theme,t,index)`; x/y arguments WORLD UNITS for methods except actor fields are CELL coords. actor kinds hero/head/segment/sentry. opts may contain theme/index/tail. Draw via r.actor, E.Blob and px, consistent shading, secondary animation. All origin conversions in rigs file for actor fields. Do not write world/background/menu. Keep sizes within tile: hero radius5.3, head radius6.3, body radius4.8, tail5.4, sentry5.3. Face lower sprite angle. Sprite-like face clear. Methods can add native lights/contact shadows.
