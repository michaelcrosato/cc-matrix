CALIFORNIROLL GAMES
Six sports. One endless summer.

Release: ../Californiroll-Games-California-Games-gpt-6.1-sol-ultra-20261105-212543.html
Open the release directly in a current browser. All engine code, physics WASM,
geometry and code audio are embedded. Optional Google Fonts download when online;
local condensed/sans-serif fonts are used when unavailable.

Build from this development folder: npm run build
All verification, failures and one count only: npm test --silent
No existing servers or shared ports are required. The test runner creates its own
127.0.0.1 server on an OS-selected port and closes it, and its browsers, afterward.

Controls: WASD or arrows / left stick to move; Space / Cross / A for action;
Shift / Square / X for tricks; Escape / Options to pause. Mouse selects menus and
can steer surfing while held. Touch: drag the left side, contextual action right.
The settings screen switches PlayStation and Xbox glyphs and exposes audio gains.
The pause menu contains instructions and live development tools.

Modes: Six-stop single-player tour, individual events, alternating two-player
couch duel, and same-browser two-tab rooms (use the same origin and room code).
True cross-device multiplayer is provided by AI Hub session protocol v1.4.0,
with authoritative host, dedicated server, shared countdown and end standings.
AI Hub sessions enter the round directly; standalone menus and dev tools do not
interrupt a network session. The official client is embedded unmodified first.

Tests: full deterministic six-event / twelve-turn simulations; Rapier collisions,
hazard avoidance and unsafe landings; real WebGPU device health; keyboard/mouse,
standard gamepad stub, touch emulation, live sliders, attract entry/exit, generated
PCM sound; two-tab synchronization; direct file release; official Hub standard,
server and host-leave with latency150/jitter50/loss5.

Software WebGPU on this machine: --enable-unsafe-webgpu --use-angle=swiftshader
--enable-features=Vulkan. The supplied --use-webgpu-adapter=swiftshader destroyed
the device, including on an isolated single-cube scene. Hardware performance,
real controller feel, actual mobile hardware and human audio listening: unknown.

Visual captures: capture-visual.py uses native GPU render-target readback to inspect
actual geometry, then composites the UI. It manages its own server and browser.
