# Content authoring

All paths are relative to this development folder. Do not edit `pixel-engine.js`. The release zip in `vendor/` is the integrity reference. Run `node tools/build.mjs` after changes and the appropriate suite behind `node tests/run.mjs`.

- **Sites:** add a record to `src/content/sites.js` with an id, name, x/z position, kind, radius and optional faction/guards. Kinds control dressing in `World.site`; existing kinds require no new code. Positions are metres, +x east, -z north, inside +/-640. Dev teleport and its coordinate readout help placement. Roads and river polylines are in `src/content/roads.js`.
- **Weapons:** add a definition to `src/content/weapons.js`, including slot, magazine, reserve, rate, damage, range, wear and price. Add the matching procedural view definition in `src/art/viewmodels.js`. Buying unlocks clean copies. Systems read balance values live rather than copying them into cached values.
- **Missions:** `src/content/missions.js` contains prerequisites, giver, pay, optional weather/hour/wind, alternate plan and steps. Supported objectives include goto, leave, use, deliver, collect, steal, report/talk, kill, destroy, burn, hold, ride, choice and named story scripts. Steps name a site or an interaction tag and supply their on-screen text. Add at least eight paired speaker/text lines in `src/content/dialogue.js`. Normal contracts appear automatically once their prerequisites resolve. Debug mission start bypasses prerequisites for authoring.
- **Interaction objects:** `World.item` supplies a stable id, tag, verb, position, model, range and properties. Use existing tags for a normal case, bed, locker, crate, speaker, shop or delivery. Place explosive objectives with HP and `explosive:true` so they acquire fuel cells, accept bullets and chain through fire.
- **People and scenery:** `src/art/models.js` exports plain native ModelDef objects and a catalog. Reuse a library prop or the person factory; palette slots must exist on the selected model. Run `node check.mjs --sheets src/art/models.js`, inspect the PNGs and run the static suite. `src/art/clips.js` and `src/art/viewmodels.js` hold 30fps native ClipDef data.
- **Writing and sound:** use the native HUD character set and short sentences. Subtitles wrap to 58 characters. Notes and epigraphs are in the dialogue content file. Music is Song data in `src/audio/music.js`; effects are SoundDef data in `src/audio/sfx.js`. Animalese voices derive deterministic syllables from the text. Music defaults and resets to 0.1.
- **Balance:** `src/content/tuning-defaults.js` defines the default, min, max and step for each live slider. The same table builds Dev Mode's Balance pages. Reset restores every value. Settings live in a separate storage key from the single versioned campaign save.

Keep interactions reachable and missions completable through their real actions. Add a test of each new rule, update the scripted playthrough when story dependencies change, and record discovered defects in `tests/ISSUES.md`. The game-state snapshot, status and fingerprint are public tooling interfaces. The multiplayer host owns health, soldiers, cases and fire; clients submit their own movement and action events, render local feedback immediately, and consume host snapshots. All session traffic passes through the session adapter.
