# Engine changes for Cricket Kerfuffle (my-3D2dge v0.85.2)
1. Humanoid `weapon: 'bat'`: a cricket bat (rubber grip, flat willow blade, sticker band) in the HD draw; the swing smear treats it like a sword.
3. Audio: a voice bus (`audio._voiceBus`), a `voiceVolume` setting in Sound ("Voices"), and `audio.bus(name)` for the game's own Web Audio nodes.
4. Button symbols: the settings default is PlayStation; the options are PlayStation and Xbox (A B X Y).
6. TileMap floor cache keeps up to 10 baked floors (was 6).
