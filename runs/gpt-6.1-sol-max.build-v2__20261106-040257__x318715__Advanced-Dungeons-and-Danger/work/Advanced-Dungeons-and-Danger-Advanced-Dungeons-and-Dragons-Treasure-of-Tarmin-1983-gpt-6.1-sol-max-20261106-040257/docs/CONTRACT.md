# Integration contract v1
Use plain ES modules. All IDs are stable strings; player IDs stringified from transport. Deterministic model owns all state, view/UI/net only read and submit commands.

Core exports `Model`, `DEFAULT_TUNING`, `validateContent`, `CONTENT` from src/core/model.js. `new Model({players:[{id,name}],seed:123,runId:"..."})`; `.state` holds JSON; `.command(playerId, action)` returns `{ok,message,...}`; `.advance(ms)` host monotonic milliseconds delta; `.snapshot()` returns cloned JSON; `.load(snapshot)` validates/restores; `.leave(id)` recovers guest gear; `.retry()` floor entry; `.setTuning(patch)` safe boundary; `.dev(action)` tools. Content has floors each `{id,name,subtitle,rows,start:{x,y,dir},...}`, items dict, enemies dict.

State: `{schema:1,contentVersion:1,runId,seed,tick,clock,floor:0,phase:"explore"|"combat"|"preparation"|"defeat"|"victory"|"ended",players:{id:Player},entities:{id:Entity},shared:{keys:[],bossDefeated:false,treasureClaimed:false},combat:null|Combat,tuning,events:[],log:[],stats,modified:false}`.
Player: `{id,name,x,y,dir:0=north 1=east 2=south 3=west,war,maxWar,spirit,maxSpirit,armor:0,ring:0,hands:[leftItemId|null,rightItemId|null],pack:[6 item IDs|null],food,arrows,down,connected,basicSpirit,seen:["x,y"]}`. Item IDs reference state.items dictionary `{id,kind}` (same stable instance ID when dropped); definitions CONTENT.items[kind] `{name,family,channel,power,defense,range,use,reusable,description,...}`. Entity `{id,type,floor,x,y,...}` type enemy/loot/door/gate/ladder/mural/chest/secret/treasure/camp. Enemy entity `{kind,war,maxWar,spirit,maxSpirit,armor,ring,dead,phase:1,...}`. Active fight `.combat={id,round,enemies:[entityId],intents:{enemyId:{target,channel,power,kind}},plans:{playerId:Action},deadline:null|ms}`. Events `{id,type,text,player,target,channel,amount,...}` capped 48, log strings capped 8.

Commands: `{type:"move",dx,dy,epoch?}` absolute one orthogonal tile (orientation separate); `{type:"turn",delta:1|-1}`; `{type:"interact",target?:entityId,choice?:"confirm"|"disarm"|"open"|"war"|"spirit"|"balanced"}`; `{type:"pickup",target,swap?:0..5}`; `{type:"attack",target?:enemyId,source?:"right"|"war"|"spirit"|itemId}`; `{type:"guard",channel?:"war"|"spirit"|"both"}`; `{type:"retreat",confirm:true}`; `{type:"equip",slot:0..5,hand:0|1}`; `{type:"swap"}`; `{type:"use",item:itemId}`; `{type:"drop",slot:0..5}`; `{type:"rest",confirm:true}`; `{type:"descend",confirm:true}`; `{type:"resume"}` preparation next phase; `{type:"handoff",item,target:playerId}`; `{type:"revive",target:playerId}`. In combat committing those tactical commands commits once, resolves after both plans or deadline; UI selection itself never calls model. Result of unconfirmed rest/gate/ladder/retreat includes `{confirm: true,message}`; full pickup `{full:true,...}`. UI can preview from state independently.

Net exports `Network` from src/net/network.js. Construct `new Network({onState(snapshot),onStatus(text),onEnd(reason),onMode(mode,localId),onReady(),onStart()})`; `.model` host/local model, `.state` latest, `.localId`, `.mode` solo/rtc-host/rtc-guest/hub, `.isHost`, `.server`, `.running`, `.ended`; `await .initHub()` returns boolean, handles AIHub lifecycle auto start/ready (renderer readiness callback via `.ready()`); `.startSolo(snapshot?)`; `.send(action)`; `.tick()` authority timer own interval; `.close()` cleanup; `await .host()` returns offer code; `await .join(offerCode)` returns answer code; `await .accept(answerCode)`; `.cancel()`; `.finish(won)` exactly once; `.ready()` after render or directly if server. No source files fetched at runtime. Real RTC handshake and initial state; no local storage or renderer in server. Clock independent rAF. Hub traffic at 8Hz chunks <16KB reliable.

View exports `DungeonView` from src/view/view.js; constructor `(game, {getState:()=>state,getPlayer:()=>player,getSettings:()=>settings,onReady,onError})`; `await .init()`; `.update(dt)`; `.draw(r)`; `.look(dx,dy)`; `.resetLook()`; `.dispose()`; `.rendererName`. Use native E.World3D lifecycle, E.Humanoid/E.Blob/E.Attack/E.Combo extensions. No UI (UI DOM overlays). Title view should show original lantern dungeon with eye mural and sentinel preview when no state (create cosmetic showcase); dungeon when state exists; first person hands in overlay (native pen). State floor changes rebuild view.

Audio exports `GameAudio` from src/audio/audio.js constructor `(game)`; `.unlock()`, `.update(state,settings,paused=false)`, `.event(event)`, `.stop()`, `.metrics()`, `.offlineProbe()` finite output tests. Settings music=.10, effects=.65, voice=.35, mute=false, reducedMotion=false. Base engine procedural synth and original music. Audio starts after gesture only.

Root owns src/main.js, src/ui/*, shell HTML/CSS, build scripts, integration tests and canonical report. Agents only edit assigned module trees and their own tests/docs, avoid bootstrap/build output. Notify contract deviations immediately.
