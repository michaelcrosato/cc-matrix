Kartesian Derby is a single-file, cel-shaded WebGPU kart racer inspired by Mario Kart 64, playable by up to four people.

- In this folder, run `python3 -m http.server 8080`. Opening the file directly will not start the game.
- Open `http://localhost:8080/Kartesian-Derby-Mario-Kart-64-for-N64-grok-4.7-xhigh-20261027-1637.html` in a browser with WebGPU.
- Drive with a controller, or WASD, Space (hop), F (item), C (camera), and Esc (pause). After 10 seconds with no input, the title screen plays an AI demo.
