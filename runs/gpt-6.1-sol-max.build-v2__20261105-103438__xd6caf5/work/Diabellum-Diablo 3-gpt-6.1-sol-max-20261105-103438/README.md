# Diabellum

Every soul counted. Except yours.

An original gothic action RPG built from `PLAN.md` on my-3D2dge v0.89.1. The single HTML file in the parent folder plays offline: open it directly in a browser. No server, account or asset download is needed.

Choose one of four parishioners. Carry Mother Quillon through three chapters, collect the iron Tongue, recast the Bell and face the Angelus. The Long Vigil offers seeded dungeons, composed Wardens, tiers, Greater Vigils and records. There are 32 skills, 96 Tones, Vows, 24 Relics, four equipment sets, gems, town services, followers and a secret field.

The campaign is a condensed complete demo. It includes its ending. Optional motion-capture clips and WebGPU lighting are omitted; the native canvas lighting remains available everywhere. All art, music, sound and gibberish voices are generated by code. Music defaults to 10%.

## Controls

| Action | Keyboard / mouse | Standard controller |
|---|---|---|
| Move | WASD, arrows, or hold click on ground | Left stick |
| Primary / skill 2 | Click / right click, or F / G | Cross / Square |
| Skills 3-6 | 1, 2, 3, 4 | Triangle, Circle, R1, R2 |
| Evade | Space | Right stick flick or R3 |
| Potion / interact | Q / E | L1 / L2 |
| Town portal | T | D-pad up |
| Map / bag / skills | M or Tab / I or C / K | D-pad down / left / right |
| Journal / pause | J / Esc | Create / Options |

Hold Shift to stand and attack. Hold Interact to revive an ally or strike the final bell. Consecrate unknown items in the bag, then equip them. L1/R1 or bracket keys change panel tabs; arrows, Enter, Escape, hover and clicks navigate the same screens. Settings includes Xbox glyphs. Touch-only devices show a controller/keyboard notice and can watch the attract reel.

A second controller joins with Options, up to four players sharing one screen. In an AI Hub session the game opens directly into a shared-world Vigil for 1-4 networked players. All network communication uses the unmodified AI Hub session client.

## Development

`npm install` uses the pinned Playwright version and the machine's installed browsers. `npm run build` produces the root HTML and `exit-interview.json`. `npm test` is the single full test command. Select a suite with `node tools/test.mjs data`, `sim`, `play`, `browser` or `hub`; comma-separated names run a chosen group. `browser --matrix` adds the 14 viewport matrix; `hub --quick` omits only the extra real-minute synchronization run.

Dev Mode is in the pause menu. It offers live balance sliders and resets, cheats, monster/item/boss spawns, travel, overlays and a living Gallery. See `game/CONTENT.md` for adding content. Useful links are `#zone/nave`, `#boss/regent/1`, `#vigil/3`, `#gallery/skill/knell/2`, `#gallery/boss/angelus/2`, `#attract`, `#about` and `?seed=1441`.

`PROGRESS.md` in the parent folder records the build and verification. The About screen and the machine-readable interview share the metadata in `game/src/data/04-about.js`.
