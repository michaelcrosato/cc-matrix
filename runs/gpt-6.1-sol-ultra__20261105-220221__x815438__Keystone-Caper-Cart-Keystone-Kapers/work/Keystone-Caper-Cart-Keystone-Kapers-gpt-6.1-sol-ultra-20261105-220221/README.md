# Keystone Caper Cart

An original three-case arcade pursuit inspired by Keystone Kapers (Activision, 1983). Side-on cel-shaded 3D, a four-floor department store, timed lift shortcuts, one-way escalators, jumping, ducking, loot and a rooftop finale.

The distributable is the matching `.html` in the parent folder. Open it directly in a modern browser with an internet connection. Three.js R180, Rapier 0.19.3, optional fonts and standalone PeerJS are loaded from CDNs. WebGPU is preferred; Three.js's WebGL 2 fallback is available when WebGPU is absent. All art, music, sound effects and voices are generated by code.

## Controls

- Move: left stick, D-pad, A/D or left/right arrows.
- Jump: Cross (Xbox A), Space.
- Duck: Circle (Xbox B), S/down.
- Cuff / board lift: Square (Xbox X), E; hold up to enter an open lift.
- Pause: Options/Menu, Escape.
- Couch player 2: arrows, Right Ctrl to jump, down to duck, Enter to cuff/lift; or a second controller.
- Touch: invisible left movement stick; tap the right side to jump. Nearby hazards and cuffs are assisted. A cuff action appears when in reach.

Catch Sid Slip before closing time. Four badges are shared across three increasingly difficult cases. Radios, balls and carts take six seconds on contact; planes take a badge. Escalators rise automatically. The centre lift cycles through the three indoor floors; it exits at the next stop. Use it to cut across the crook's lead in the final case. The roof is reached by escalator.

## Modes

Solo; two-player couch patrol; one-to-four-player online co-op with room codes; AI Hub Session Protocol v1 shared-world sessions, including spectator hosts. The host runs physics and shares the world. The title starts an AI patrol after ten seconds; any input returns to the title. A pause-menu developer desk provides live tuning, invulnerability, slow motion, case skip, resource refill and defaults.

## Development

`npm run build` uses the installed Bun bundler and Python to produce `index.html` here and the named single-file release in the parent folder. No npm installation is required.

`npm test` runs the complete regression suite and starts its own loopback server on an OS-selected port. It prints failures and a one-line count. Python Playwright is invoked from this workstation's installed pipx environment. The test runner includes real Rapier simulations and a default-tuning full playthrough; browser keyboard and emulated standard-controller controls; pause/developer/settings/about/attract; touch; synthesized audio measurements; same-origin four-player networking; direct internet WebRTC; and all four official AI Hub harness scenarios. Detailed results are saved in `test-results.json`. The local pinned Rapier test dependency is in `test-deps/rapier`.

`exit-interview.json` in the parent folder contains catalogue metadata, source information and the exit interview. The in-game About & Credits screen contains the same information. Usage is deliberately left as “added on import.”
