# Wobble Fit

The full development workspace for the self-contained Little Fulcrum balance game. Start with [the game README](labs/game/README.md). The engine is pinned and read-only; its exact provenance is in engine-lock.json and ENGINE-FEEDBACK.md.

Build: `node labs/game/tools/onefile.mjs`. Verify: `node labs/game/tools/verify.mjs`.
