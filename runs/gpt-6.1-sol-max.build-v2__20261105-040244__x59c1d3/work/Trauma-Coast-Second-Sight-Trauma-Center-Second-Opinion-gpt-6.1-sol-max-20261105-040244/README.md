# Trauma Coast: Second Sight

Original first-person surgical action, a complete eight-case hospital thriller, made on the full my-3dge workspace.
The game and its controls, authoring data, developer tools, packaging and verification are documented in
[labs/game/README.md](labs/game/README.md). The self-contained playable HTML and exit-interview.json are delivered one
folder above this workspace. PLAN.md and TASK.md there define the requested scope.

Run npm ci, npm run bundle and npm run verify. The engine is pinned at 6a1501f and remains unchanged.
