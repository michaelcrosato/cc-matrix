ENGINE FEEDBACK
- What did you like most about the engine? Three.js r180 WebGPURenderer and its built-in MeshToonMaterial take a gradient map, so cel shading needed no custom shader code.
- Did you get stuck or guess wrong? Yes. Boss health read 0 because I never set a max value. The pilot and missiles aimed at the shielded boss centre instead of the side pods. Both showed up only in an unattended playthrough, so I now run one.
- What was the most important thing you had to build yourself? The mission timeline, lock-on, and the swept-collision layer. Rapier provides bodies and contacts only.
- What was the hardest part about using the engine? Rapier's init prints a wasm-bindgen deprecation warning in console. The WebGPU adapter is only available with specific Chromium flags on headless Linux.
- If you had to remove or overhaul one thing from the engine, what would that be? The positional init call that triggers the Rapier warning.
- If you could change one thing about the engine, what would it be? A built-in swept-collision helper for fast projectiles.
