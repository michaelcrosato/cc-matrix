# E.T. the Extra-Trusting

An original affectionate adventure inspired by E.T. the Extra-Terrestrial (1982).

- Elevated third-person bicycle exploration in a hand-built moonlit, ink-outlined suburb and redwood forest.
- Three salvage pieces, moving searchlight patrols, candy distractions, hush riding, a recovering bond, restorative glow, a living creek bridge, flowers and a three-note transmitter puzzle.
- Six-ring levitating bicycle escape, landing, a staged farewell and complete ending; checkpoint rescue, saved journey, replay and free ride.
- Native Three.js AnimationMixer/AnimationClip for rider, bicycle and passenger animation. WebGPU via Three.js r180, Rapier 0.19.3 kinematic collision and dynamic candy, Web Audio synthesis, Gamepad API.
- Controller-first menus, adaptive PlayStation/Xbox/keyboard hints, mouse world interaction, touch assistance, map, settings, credits, live developer tools from Pause.
- Ten-second title idle timer starts an autonomous looping tour. Input returns to the menu.
- AI Hub Session Protocol v1 shared-world authoritative host; standalone BroadcastChannel + PeerJS WebRTC rooms, four seats, no chat.
- Bundle all runtime libraries and WASM into one portable HTML. No runtime art, sound, fonts or module downloads.
- One quiet command tests startup, a complete real simulation playthrough, mechanics, inputs, audio, save/settings, standalone multiplayer and the official Hub harness scenarios. Screenshots only for visual review.
