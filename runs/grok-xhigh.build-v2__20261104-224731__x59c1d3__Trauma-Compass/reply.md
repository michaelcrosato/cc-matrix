Trauma Compass is a single-file browser surgical game for one to four players, on the couch or in an AI Hub session.

- Open `Trauma-Compass-Trauma-Center-Second-Opinion-grok-4.7-xhigh-20261104-224731.html` in Chromium with WebGPU. Firefox and WebKit only show that WebGPU is required.
- Aim with the mouse or left stick, use the tool with click or R2, switch tools with 1–8 or the right stick, and pause with Esc or Options.
- Run `npm run verify` in the game’s dev folder to rerun the checks.
