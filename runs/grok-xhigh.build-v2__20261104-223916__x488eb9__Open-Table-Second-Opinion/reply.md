Open Table Second Opinion is a self-contained surgical-action browser game — eleven cases, story, ward, and local or AI Hub co-op — in one HTML file.

- Open `Open-Table-Second-Opinion-Trauma-Center-Second-Opinion-grok-4.7-xhigh-20261104-223916.html` in a browser. It runs from `file://` with no server.
- On the title, press Enter, Space, or Start, then choose New Game. The mouse aims in surgery; left click or Space uses the tool. A gamepad works too.
- From the matching dev folder, `node tests/run.mjs` runs the checks.
