# Game and wire contracts

The engine uses its native 1/120-second update. Arena is always 640 × 360; view dimensions only center decoration. The FORMATION kit's step/draw boundary is retained, with a new simulation instead of its generic ship/bomb rules. The engine's alternating-turn arcade ledger is not used.

`BCP.createRun({seed,seats:[1,2],rng,content,tuning,demo})` creates a rendering-independent authoritative world. `BCP.applyAction(world,seat,{move,aim,fire,call})` validates the current seat action; call is a monotonically increasing request counter. `BCP.step(world,dt)` advances one tick and creates ordered gameplay events. `BCP.snapshot(world)` exports a complete JSON view. `BCP.finish(world,won,reason)` is idempotent. Only authority changes resources/collisions. Renderer rigs/effects follow entity IDs and event IDs and never score.

State: tick, seed, time, status (intro/live/harvest/intermission/win/loss), encounter index/time, pending entries, players, bees, obstacles, pulses, flowers, growth warnings, bird state/target, boss phase, score, reserves, claimed rewards, earned thresholds, statistics, coverage and result. Events carry monotonic ID, tick, kind, position and small payload; a bounded recent ring is for presentation, not state recovery. Stable encounter/entry reward identities survive enclosure retries. Hit, feed, hive and clear claims are distinct. Renewable boss escorts have eight scoring identities per phase; later rescues cannot generate points.

Worker boundaries/comb contacts descend at most one tier per tick. A genuine narrow corridor sustained for the tuning's trap delay constructs a hive without tier teleporting. Removing its boundaries cancels construction. Pulses sweep upward against current contacts ordered by travel time then entity ID, carry two bee hits, ignore their own newborn combs, and stop at any existing obstacle or bird. Contacts/score/stock settle before enclosure/exhaustion; encounter clear wins a terminal race.

Wire version 1: client `{v:1,k:'input',seq,move,aim,fire,call}` (sender is the seat identity, never trust a claimed seat). Host `{v:1,k:'state',seq,ack,state}`. The compact state uses packed entity arrays and includes full current geometry, resource totals, phase, pending timeline and recent events. Only SDK host messages are accepted. Inputs at 10 Hz, snapshots at 8 Hz plus one reliable checkpoint when phase/encounter changes (batched with the next scheduled send). Inputs expire after 450 ms. Stale sequences/call counters are ignored; all numeric fields must be finite and clamped. Packet budget <16 KB, <20 sends/sec. No secondary network transport.

Hub lifecycle handlers are registered before connect. Ready once without gesture, tick only after start and SDK time >=0, host-only idempotent finish, immediate time-up result, end stops sends/simulation/audio. Server host has no local player input. Local options neutralize only that seat; no world pause/restart/dev tools in Hub. Leaving removes a can without charging stock; future traffic adjusts at the next encounter boundary.
