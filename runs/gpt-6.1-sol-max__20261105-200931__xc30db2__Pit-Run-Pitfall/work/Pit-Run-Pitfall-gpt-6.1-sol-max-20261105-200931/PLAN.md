# Pit & Run

An original cel-ink jungle platform adventure inspired by Pitfall (1982).

- 2.5D side view; six treasure seals across six authored regions.
- Rapier capsule physics, buffered jumping, ladders, pendulum vines, crocodiles, snakes, logs, scorpions, fire, checkpoints and a final gate.
- Three.js r180 WebGPU, procedural inked geometry and native AnimationMixer rigs.
- Synthesized music (10% default), effects, gibberish voice and jungle ambience.
- Keyboard/mouse, standard gamepads, touch assistance; TV-scale focus navigation.
- Couch party (1–4), host-authoritative AI Hub co-op, standalone direct WebRTC link and local tab relay.
- Title attract replay after ten idle seconds; pause/settings/how-to/about; developer tuning and travel tools.
- Build: node build.mjs. Tests: bash test.sh (only failures and one summary).
- Dependencies remain CDN downloads in the delivered single HTML; vendor copies are for repeatable QA.
