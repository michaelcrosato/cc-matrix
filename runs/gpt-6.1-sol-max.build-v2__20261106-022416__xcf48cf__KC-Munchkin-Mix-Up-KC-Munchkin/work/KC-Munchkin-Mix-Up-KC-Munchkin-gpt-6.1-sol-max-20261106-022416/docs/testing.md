# Verification evidence

Run `node tools/test.mjs` (or `npm test`) in this directory. It captures noisy child output and prints only failures and one passed/failed/skipped count. Targeted `--unit`, `--browser`, `--touch`, `--hub` and `--hub-live` checks use the same entry point. Reports are generated under build/reports/; screenshots under build/screenshots/.

The release evidence is recorded in build/reports/final-verification.json and PROGRESS.md. It preserves the complete 157-check run and the 60-check final browser regression; the latest per-suite coverage contains 159 distinct passing checks. latest.json reflects the most recent selected command. The suites are not FPS gates.

- Simulation: expiring turn buffers, neutral release, immediate reversal, stick hysteresis, walls, explicit tunnel seams, swept swaps, twelve unique moving identities, monotonic acceleration, deterministic simultaneous co-op collection, pickup-before-hit ordering, bounded power/chain, warning and recharge, harmless returns, damage grace, affected-only respawn, final-bite clear and zero-life failure.
- Content: all five authored layouts plus the generated campaign board in every gate orientation, measured useful shortcut, 64 reproducible seeds, twenty normal-rule remix catches, strict imported metadata/IDs, actionable corrupt/disconnected board errors, workshop undo/redo/save/reload/code/play, unavailable/corrupt persistence.
- Lifecycle: two whole-campaign legal-intent traces (solo/co-op), six final-target catches each, normal lives and speed, actual final HTML campaign/results/retry, native settings persistence/reset, ten real idle seconds, repeated attract exits with consumed input and no record pollution, live developer sliders/reset and assisted-record exclusion.
- Controls: real keyboard/mouse events, native hover focus, standard-map pad stubs, last-device labels and PS/Xbox selection, Create+Options reservation, controller loss, two independently assigned local pads, phone/tablet profiles with real multi-contact CDP input, chirp/menu while holding a steering contact, cancellation and touch workshop selection. WebKit receives a focused iPhone-profile boot/play pass.
- Audio: OfflineAudioContext runs every game SFX through native synthesis and each formant voice vowel; finite samples, non-silent output and bounded peaks are checked. Native music/SFX/voice buses, the single 10% music gain, mute and synchronized pause are checked. There are no audio files in the bundle.
- Hub: original official harness for one seat, two seats, impaired network, host leave and dedicated host. `window.__hubCheck.pass` must be true. A longer legal-input dedicated run checks actual collections, score/lives/gate/mask/revision and actor coordinates against retained authoritative packets, stage repair, sender/sequence rejection, local-menu continuity, missing heartbeat, player leave, tied co-op reporting, partial time-up, exactly-once finish and terminal silence/transport freeze.
- Package: standalone file opening, no local/CDN resource requests, first-script byte-identical session client, strict metadata/interview shape and correct catalogue title. Pinned vendored repositories have no local changes. MIT permission text is embedded with the engine.

Physical DualSense/TV/phones/tablets/iOS, human listening quality and a first-time human campaign duration are unknown. Browser/device/controller stand-ins are explicitly used; these environmental limits are not silently counted as hardware passes. All owned browser contexts and temporary 127.0.0.1 servers close in finally blocks. No neighbouring processes or fixed ports are touched.

Nine unique issues are recorded in docs/issues.md. Test fixture mistakes (including asynchronous input waits and multi-contact CDP release IDs) are separate from game issue counts.
