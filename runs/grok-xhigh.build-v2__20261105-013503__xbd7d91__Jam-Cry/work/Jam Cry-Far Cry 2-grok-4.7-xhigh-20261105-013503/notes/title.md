# Title roll

Process: 50 playful riffs on the source title, then one index from a cryptographic RNG (`secrets.randbelow`, seeded by `os.urandom`). The game on screen uses only the chosen title.

## RNG

```
INDEX 46
TITLE Jam Cry
```

`secrets.randbelow(50)` returned 46.
