# Engine changes (v0.85.2 -> Crackmania)
- E5 (2D, input + settings): `input.glyphs` defaults to `'playstation'`; the `glyphs` setting offers PlayStation (default) and Xbox only.
  Why: TASK.md wants PlayStation glyphs by default with an Xbox option in Settings.
- Nothing else in the engine was changed: the game uses `world.track`, `world.vehicle` (E.Car handling), `World3D` levels with pits for the jump gaps, the pen for gates, split screen, players, the shell's pause menu (with a Dev Mode item) and settings as they ship.
