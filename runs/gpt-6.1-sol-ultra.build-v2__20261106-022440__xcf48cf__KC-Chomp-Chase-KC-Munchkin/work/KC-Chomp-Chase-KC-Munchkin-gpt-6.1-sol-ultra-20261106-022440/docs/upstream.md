## Network adapter contract

`await ChompNet.create(callbacks)` returns `null` outside Hub. It registers lifecycle and message handlers before connecting, then automatically prepares the common world and calls ready. Callback names: `onPrepare(players, seed, role)`, `onStart(data)`, `getState()`, `onState(state, metadata)`, `onIntent(stringSeat, {dir:null|0..3, action:boolean})`, `onLeave(stringSeat, data)`, `onTimeUp(data)`, `onEnd(data)`.

The returned adapter exposes `isHost`, `isServer`, `localSeat`, `players`, `live`, `ended`, `finished`, `time`, `rng()`, `input(intent)`, `tick(dt)`, `transition()`, `finish({score,won,stats})`, `diagnostics()` and `dispose()`. `tick` runs even while local settings are open. Only a true `live` and `isHost` allows advancing the common world. Local host input goes directly to the host callback; remote intent uses sender authentication and a .65 second missing-heartbeat reset. Dedicated hosts have no local seat. Remote intent is capped below 15 Hz, heartbeat 5 Hz. Host sends 10 Hz unreliable states and 2 Hz reliable repair states, plus a reliable transition. On back-pressure, only the latest reliable repair is retained. Revision, tick and packet sequences reject stale state. Snapshot JSON is bounded to 16 KiB.

Network snapshots select the view's real state (exact positions, directions, food IDs/mask, timers, lives/score, gate, animation signals and bounded events), excluding authoritative route-planning internals. Record-table encoding sends shared object field names once and reconstructs the native objects, including the actors/players alias. Reliable repairs carry board/config/stats; routine packets reuse the current revision's static board. A new revision's unreliable state waits for its matching reliable board. An initial probe measured approximately 1.5–1.8 KiB routine messages and 3 KiB repair messages, rather than the original 8 KiB snapshot. These exceed the aspirational 1,200-byte unreliable target but remain below protocol limits and passed the official 5% packet-loss test. All state repair is absolute; no cumulative delta chain can lose a collected snack.

Diagnostics retain at most 24 transmitted state summaries and one accepted summary, keyed by packet sequence. This lets tests compare exact actor/food/enemy state, mask, lives/score, power, gate and revision at one authoritative instant despite latency. Diagnostics do not grant write authority.

`onTimeUp` returns a synchronous result; the adapter finishes once inside the grace window, with a tied group of remaining real players, identical team-score copies, explicit win status and per-seat statistics. `onEnd` must stop all gameplay, menu input and audio in the caller. No traffic is accepted or sent afterward. ChompNet uses only AIHub transport; it does not provide standalone internet matchmaking.

## Scoped verification

`node tools/hub/network-test.mjs` exports `networkTests()` for the main test entry and currently covers 13 authority/lifecycle/state-repair invariants. `tools/hub/check.py` uses the installed Playwright Python interpreter, an owned loopback server with an OS-selected port, and one browser. Its five official scenarios are one player, two players, two players with 150 ms latency / 50 ms jitter / 5% loss, host leave, and a dedicated server. It additionally compares exact authoritative snapshots, verifies real movement and terminal silence, and runs a legal-input accelerated board transition under loss. The accelerated boundary is separate from whole-campaign completion evidence.

Final rebuilt-artifact run: 95 checks passed, 0 failed, 0 skipped; all six official-harness reports have `__hubCheck.pass === true`. Exact shared-state comparisons numbered 76 normal, 78 impaired, 43 host-leave, 124 dedicated and 3 at the impaired boundary, with no mismatch. The boundary test used 2,356 normal 1/120-second steps (19.633 simulated seconds), cleared the actual first board with five lives, advanced revision 1→2 and stage 0→1, and reset the new board's food mask to 4095. After injecting a stale prior-stage snapshot, guests retained the new revision. Time-up produced one tied co-op result with score 20 for both real players, `won: false`, one completed stage and twelve remaining snacks. This is accelerated boundary evidence, not a claim of real-time campaign pacing. All owned servers/pages/browser processes were closed.
