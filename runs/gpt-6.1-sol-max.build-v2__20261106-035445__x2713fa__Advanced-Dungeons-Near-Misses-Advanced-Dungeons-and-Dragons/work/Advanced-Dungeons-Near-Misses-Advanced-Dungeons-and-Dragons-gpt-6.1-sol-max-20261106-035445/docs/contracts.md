# Shared implementation contracts

All game modules are standalone IIFEs extending `globalThis.NM`. Bundle order: config, content, geometry, simulation, art, audio, input, network, UI, main. No ESM runtime imports. Node tests may load config/content/geometry/simulation in a vm. All simulation positions use world units: 16 units = one tile. Authored content coordinates use tiles and are converted only by Geometry.compile.

## Content
`NM.Content = {version:'near-misses-1', caves:[...], landmarks:[...], routes:[...], enemyDefs:{...}, validate()}`.
Each cave is `{id,name,subtitle,palette:{floor,wall,accent,ambient}, width,height,rooms:[{id,name,x,y,w,h,clue,kind}], passages:[{from,to,via?:[[tileX,tileY],...]}], spawn:[x,y],exit:[x,y],reward:'axe'|'boat'|'key'|'dawn'|'dusk',enemies:[{id,type,x,y,room}],supplies:[{id,x,y,kind:'arrows'|'heart'|'treasure',amount}],tools:[{id,kind,x,y}],banks:[{id,ax,ay,bx,by}],tracks:[{id,x,y,type,angle}],triggers:[{id,x,y,radius,text,objective?}],guardIds:[id],safeAnchors:[[x,y]], criticalPath:[roomId]}`. Rooms are floor rectangles; passages carve width-three orthogonal corridors between room centers, optionally through via points. Exit ladder requires reward and guardIds defeated. Rewards dawn/dusk correspond to defeated guardians. Use 7+7+7+4+4 meaningful rooms and optional alcoves. No isolated rooms. Bank segments must not bisect the full traversable corridor. First cave has safe shooting/recovery and supply before encounters. Second has mandatory safe bank target + useful corner. Third ooze has alternate route. All supplies before mandatory bosses. Stable globally unique IDs. Enemy types rat,snake,bat,spider,ooze,drake,guardian1,guardian2.
Landmarks `{id,name,x,y,kind,cave?,clue,requires?}` use normalized miniature map positions 0..1. Routes `{from,to,requires?}`. Core chain cave0 -> axe/forest -> cave1 -> boat/river -> cave2 -> key/wall -> cave3 -> cave4 -> ending. Designer docs demonstrate one optional authored room.

## Simulation / rendering
`NM.Sim` class owns `state`, `config`, `step(dt)`, `command(seat,cmd)`, `addPlayer(seat)`, `removePlayer(seat)`, `loadCave(index)`, `restart()`, `snapshot()`, `applySnapshot(s)`. `cmd` = `{mx,my,ax,ay,focus,sprint,fireId,interactId,dodgeId,interactHeld,seq,epoch}` normalized vectors. Actions are monotonic IDs, authority deduplicates. State fields: `{tick,time,mode:'map'|'cave'|'victory'|'defeat', caveIndex,seed,players:[],enemies:[],arrows:[],pickups:[],noise:[],events:[],party:{ammo,capacity,reserves,tools:[],halves:[],cleared:[],treasure},stats:{...},explored:[],visible:[],arrowLit:[],checkpointId}`. Actor `{id,seat?,type?,x,y,z?,angle,hp,maxHp,state,stateTime,invuln,draw,recovery,focus,downed,walk}`. Enemies include `homeX,homeY,targetX,targetY`. Projectiles `{id,x,y,vx,vy,bounces,owner,life}`. Events `{id,kind,x,y,time,...}`. Static `sim.level` has compiled grid and content; dynamic state JSON-serializable. Rendering MUST NOT mutate simulation.

## Network
`NM.Network` is game-owned controller constructed with callbacks `{getState:()=>snapshot, applyState:s=>..., command:(seat,cmd)=>..., addPlayer:seat=>..., removePlayer:seat=>..., start:({role,seats,localSeat,hub})=>..., ended:reason=>..., status:text=>...}`. Expose `connectHub()` returning boolean, `host()` async invitation string, `join(invitation)` async reply string, `accept(reply)` async, `sendInput(cmd)`, `update(dt)`, `finish(win,stats)`, `close()`, diagnostics. If interface needs changes, coordinate first. Authority state snapshots capped to 16KB and traffic <=20/s/copy including startup. Hub no local avatar on dedicated server. Pure offline never opens RTC. Manual pairing validates version/content/nonce/roles. Node protocol tests + Python production RTC and real vendored harness tests owned by network contributor.

## Native art
`NM.Art` provides stateless drawing adapters using the full engine native shaded primitives, Humanoid rig/pose hooks and original creature forms. See renderer integration agreement with root before writing. Root owns render/render.js, scene/camera/fog/UI; art contributor owns render/art.js only and native animation docs/tests. Art functions take engine game/draw/view plus simulation actor and draw in engine world units. No DOM or simulation mutation.
