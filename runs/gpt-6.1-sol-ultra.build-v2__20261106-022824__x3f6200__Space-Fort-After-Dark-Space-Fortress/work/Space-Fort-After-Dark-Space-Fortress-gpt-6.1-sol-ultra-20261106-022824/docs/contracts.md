All code plain IIFEs extending globalThis.SF. Logical arena 960x540, fixed 1/120 step. Engine overhead renderer, ground geometry still x/y screen plane.
SF.World({seed,players:[{id,name,seat,color}],attract=false,limitMs=780000}) owns .s serializable state. step(dt,intents array indexed by seat or id map). snapshot() deep copies; restore(snapshot). choose(id,0..2). dev(action,value). bot(player) returns intent using real tools.

Player: id,name,seat,color,x,y,vx,vy,angle,hp,maxHp,energy,pulse (0 ready, cooldown sec),fireCd,boostT,invuln,respawn,upgrades:[laser,boost,pulse],flash,lock,active,lastSeq.
