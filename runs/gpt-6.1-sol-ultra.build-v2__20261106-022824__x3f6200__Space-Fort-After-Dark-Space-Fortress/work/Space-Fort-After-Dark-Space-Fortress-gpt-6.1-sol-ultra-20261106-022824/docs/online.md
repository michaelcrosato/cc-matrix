# Shared-world networking

The Hub protocol1/client1.4.0 owns transport, synchronized launch, identities, departures and results. The host owns the only gameplay simulation. A dedicated copy uses the same explicit clock without a local pilot, input surface or renderer. Menus neutralize the local pilot while authority continues. Sequence-checked client intents expire after400ms; one-frame abilities are latched until the next transport send and each remote action edge is applied once per input sequence.

Each copy emits at most16 scheduled game packets per second (unit checks bound any one-second window to18). The host alternates compact player/objective/boss motion with compact entity/projectile batches and reliable complete keyframes. Routine unreliable JSON is bounded to1200bytes. Complete state table-packs repeated entity keys, quantizes replica floating values to0.01, and splits into6000-character reliable parts below the16KB hard limit. A keyframe is restored only when every part is assembled; duplicate, stale and wrong-sender state is ignored. Periodic complete state recovers enemies, projectiles, hazards, resources, upgrades, outcomes and event sequence. Host simulation precision is unchanged.

Only the local client's movement is predicted. Input is sampled every1/120s using the same normalized movement, live thrust/drag balance, boost direction/cadence, arena bounds, ground carriage constraint and fortress hull boundary as the authoritative movement. The predictor changes only the rendered pilot pose and velocity. It never changes energy, hull, pulse readiness, projectiles, damage, score, objectives or results.

Prediction keeps input samples tagged with their outgoing sequence. Each authoritative player update supplies `lastSeq`; acknowledged samples are dropped and at most220ms of recent unacknowledged movement is replayed from the authoritative pose. Corrections within90px use an exponentially decaying offset capped at20px; larger corrections snap. Total visible lead is bounded to48px in flight,72px during boost, and24px under a known tractor lock or nearby gravity anchor. Corrections and prediction are constrained by the same arena/station geometry. Countdown, local overlay, cinematic/intermission, death and end disable prediction and discard pending prediction history. Keyframe recovery applies authoritative pose/resources and reconciles any newer acknowledged motion. Remote pilots use bounded interpolation/extrapolation instead.

Evidence: `tests/online.mjs` includes23 unit checks, including immediate local motion before a150ms response, overlay stop, acknowledgement pruning, release convergence, ground boost, station exclusion, hazard lead bounds, full recovery and absence of provisional rewards. `tests/hub_gameplay.py` exercises real native input, remote control, countdown, overlays, authoritative clock catch-up, state convergence and lifecycle cleanup in the official harness. `tests/hub_browser.py` runs official1–4-player/adverse-network/host-departure/dedicated conformance scenarios.
