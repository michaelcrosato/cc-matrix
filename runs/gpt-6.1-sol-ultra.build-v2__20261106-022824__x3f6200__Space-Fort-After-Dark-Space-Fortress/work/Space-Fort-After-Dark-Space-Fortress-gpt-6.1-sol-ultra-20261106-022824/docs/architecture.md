# Architecture and decisions

The unmodified my-3D2dge 0.89.1 engine supplies native pixel drawing, sprite/animation frames, hue ramps, fixed-step input and clock, Shell menus/rebinding/settings, procedural synthesis and music/SFX/voice buses. The released AI Hub 1.4.0 client is the first script after charset and is embedded byte-for-byte. Application modules are bundled as ordinary inline scripts. No asset downloads, local imports or external runtime libraries are required.

world.js owns serializable deterministic state and a xorshift32 world RNG. All authoritative gameplay uses 1/120-second steps. Renderer randomness is a separate pure hash; drawing cannot change a run. Fast projectiles use swept segment/circle collision. Stable entity ordering and failure-before-success resolution prevent duplicate or contradictory results. The complete state includes all resources, upgrades, hazards, projectiles, objective state, result, processed sequences and live balance.

The native engine is created with loop:false and stepped by one elapsed-time scheduler. RAF only draws with advance(0). Hub authority also bounds world time by AIHub.time, remains live under local menus, and runs without a local pilot or render surface on dedicated hosts. Only the host applies gameplay; clients send validated own-seat intents with expiry and action edge latches. Traffic stays below the shared 20-message/second limit. Small motion/detail packets stay below1,200bytes; larger recoverable keyframes are reliable bounded chunks assembled atomically. End shuts down gameplay, traffic, voices and input-dependent actions.

Three small integration adapters extend native behavior without changing the vendor source: fractional fixed-arena scaling below one device pixel; explicit engineering units for dev sliders; and non-P1 couch navigation on that seat's refit page. Native menus, key rebinding, controller polling/deadzones, sprite animation, and audio buses remain the foundation.

Scoring is original: hunter120, bomber220, scout150, anchor250, rammer160, tractor260, dive150, relay400 before chain multiplier. A relay adds200. A protected layer adds1,000; a forced retreat subtracts500; redeploy costs300; damage resets chain. Victory adds3,000 plus20per remaining base point. Chain ranges1–4. Authored ranks: Cadet below2,500; Lieutenant2,500; Captain7,000; Commander14,000; Star Marshal22,000. These are this game's rules, not claimed original scores.

Run upgrades apply independently: laser+30%damage and12%cadence improvement per selection; boost+35reserve; pulse recharge divided by1+.28per selection. Normal default builds and all branches win under the unmodified seeded pilot tests. Attract uses a separate clean run and explicit invulnerability; its scores never save.

Native Shell and settings persistence have blocked-storage fallbacks. Best score has a separate guarded localStorage write. Music defaults .1, with independent effects and gibberish voice controls. Oscillator handles are tracked explicitly because native custom instruments do not return source handles through the public SFX lifecycle.

Replicas predict only the local living pilot's pose. Sent input sequences tag a bounded movement history; authoritative lastSeq acknowledgments prune it, replay a short newer window, and smooth bounded correction. Prediction is disabled during countdown, overlays, death and transitions. Ground/station boundaries and tighter gravity/tether lead caps keep it recoverable. Authoritative health, resources, objective damage, kills, score and results are never predicted.
