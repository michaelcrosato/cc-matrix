# Integration contract
Title: Smithereen Royal Rumble. ES modules bundled by esbuild, global My3D2dge native engine loaded before game. Root integrates simulation + boot + build + tests. Native engine v0.89.1, Hub v1.4.0, revisions unchanged from PLAN.md.

## Simulation (root owns src/sim.js and src/content.js)
Export `DEFAULTS`, `STONES`, `COURTS`, `RIVALS`, `createWorld(opts)`, `command(w,seat,cmd)`, `step(w,dt=1/120)`, `predict(w,seat,power,type?)`, `planShot(w,seat,profile?)`, `health(w,seat)`, `resetCastles(w)`, `validateCourt(data)`, `pack(w)`, `unpack(data)`.
World: serializable `{version:1,tick,time,seed,mode,phase:'play'|'over',court:0..4,bout:1..10,limit:90,config:{...DEFAULTS},players:[p,p],blocks:[b,...],projectiles:[],events:[],stats:{shots:[0,0],used:[[],[]],collapses:0,crew:0,launcher:0},outcome:null,revision:0}`. Events retain last 200, unique incrementing `id`, `{type,seat,x,z,...}`.
Player `{seat,x:150|490,z:70,crewX:181|459,stone:0..2,charge:null|{start,power},held:false,buffer:false,reloadUntil:0,crewUntil:0,launcherUntil:0,protectUntil:0,score:0,last:[null,null,null],ai:null|{...profile}}`. `last` impacts `{x,z,target,power}` per type. `charge.power` updates during step. Cooldowns seconds against w.time. Target crew center z55, radius10; launcher x150/490,z55 radius15.
Blocks `{id:integer,seat,x,z,w,h,hp,maxHp,material:'wood'|'stone'|'reinforced',foundation:boolean,supports:[id],alive:true}` coordinates bottom-left, z up. Foundations never objectives. Array IDs globally stable. Ground z40, bank x<245 or x>395, water z19. Castle footprints seat0 x40..132, seat1 mirror640-x, z40..190. Fixed inward elevation50deg. World width640 and useful height350.
Projectile `{id,throwId,seat,type:0..2,x,z,vx,vz,fragment:false}`. Same integrate/sweep code prediction and live; split deterministic at apex. `predict` returns `{points:[[x,z],...],impacts:[{x,z,target:'block'|'crew'|'launcher'|'water'|'ground',id?,seat?,time}],power,type}`. `planShot` returns `{power,type,value,target}`; legal command AI scheduler in sim step.
Commands `{type:'begin'|'release'|'cancel'|'stone',stone?:0..2,duration?:seconds}`. Release duration allowed only online adapter validated; ordinary charge from clock. Safe cancellation clears held/buffer. No per-frame command seq required in sim. `health` returns fraction0..1. Outcome `{winner:-1|0|1,reason:'demolition'|'time'|'forfeit',scores:[n,n],banked:[n,n]}`.
Defaults units: `chargeTime:1.4,maxSpeed:290,gravity:120,reload:.9,heavyReload:1.35,splitReload:1.7,damage:1,healthScale:1,crewDisable:1.8,launcherDisable:2.6,protection:1.25,aiError:.025,aiReaction:1,assist:0`.

## Runtime (root owns src/main.js)
Global test handle `window.__rumble = app`. `app.world`, `app.game` native E.Game. `app.screen='title'|'setup'|'settings'|'controls'|'about'|'pause'|'developer'|'author'|'result'|'championship'|'play'`; `app.mode='solo'|'quick'|'local'|'attract'|'hub'`; `app.settings` with music:.1,effects:.7,voice:.45,glyphs:'PlayStation',tension:1.4,prediction:false,reducedMotion:false,uiScale:1,fire1:'Space',fire2:'ShiftRight',seat1:'keyboard',seat2:'keyboard'. `app.focus=0`, `app.online` null or adapter.
Root methods `app.start(mode,options={court,bout,seed,war,difficulty})`, `app.title()`, `app.pause()`, `app.resume()`, `app.advance()`, `app.command(seat,cmd)`, `app.setScreen(name)`, `app.saveSettings()`, `app.resetTuning()`, `app.message(text)`.
`app.menu` array `{label,sub?,action?,kind?:'slider'|'choice',value?,min?,max?,step?,change?(value)}` generated by UI. All actions callbacks. UI ownership of menu screens/content is delegated. UI can import sim/content, metadata. Root provides tour state `app.tour={next:1,totals:[0,0],seed,cheated:false}` plus `app.savedTour` validated or null; settings storage root.

## View agent owns src/view.js and src/audio.js
Export `createView(E,game)` returns `{draw(r,app),update(dt,app),clear(),worldPoint(clientX,clientY)}`. Native art, native Humanoids, backdrops, props, catapult custom animation, native particles nonfreezing. View draws battlefield and combat HUD only, UI draws menus separately. Fit complete world at all screen aspects, support phone. `app.pointerWorld` optional {x,z}; `app.device='keyboard'|'mouse'|'touch'|'pad'`; `app.caption` optional text. Root integrates draw order view then ui. May draw world on title as animated backdrop. Audio export `createAudio(E,game)` -> `{unlock(),update(dt,app),event(e,app),stop(),setVolumes(settings),diagnostics()}`. Code-only all audio, default music gain .1, separate buses. No engine edits without telling root.

## UI/input agent owns src/ui.js and src/input.js
`createUI(E,game,app)` returns `{update(dt),draw(r),refresh(),back()}`; uses native Menu/Shell helpers for focus/menu. Implement all front/pause/setup/settings/controls/results/credits/dev/author pages, rich but sparse controller-first screens. `createInput(E,game,app,ui,view)` returns `{update(dt),clear(),dispose()}`; listeners for keyboard/mouse/touch, pad polling, last device; sends app.command, updates menu focus; native menu available. Avoid double capture with native shell. Need method bindings can be appended to app. Root game input uses custom `{}` and scene pausable:false; input agent owns pause paths. `app.idle=0` reset meaningful input, attract exit consumes input by `app.title()`. Root triggers attract after idle>=10. Clear on scene changes and focus loss, ownership settings. For input menu, ui methods `navigate(dir)`, `confirm()`, `adjust(dir)`, `pointer(x,y,click)`, optional extra methods. View worldPoint uses client coords. Full menu clickable DOM overlay acceptable as supplement but native pixels + TV scalable typography preferred. Settings fire rebinding support. Developer live validated sliders and author import/export required; no hub mutations. Online screen disabled mutations.

## Online agent owns src/online.js and tests/hub* + harness
Export async `connectOnline(app)` -> adapter|null. Register before ready, active before standalone startup. imports sim. Adapter `{active:true,isHost,seat,ended,update(dt),command(seat,cmd),dispose(),diagnostics()}`. Host has app.world, snapshots clients assign app.world; root MUST skip sim stepping when app.mode==='hub', adapter controls stepping with Hub clock. No-local-player server. Adapter sets app.screen='play', app.mode='hub'; use app.message. Use exact unchanged vendor/hub/session.js first inline script. All packet budgets/retries/ACK/lifecycle per PLAN; dedicated tests through official harness. Acquire harness sibling deps if missing. Root builds final artifact at parent/<basename>.html and dev index.html. Write harness runner callable standalone; report how root can add to npm verify. Root can supply window.__rumble for gameplay hooks.
