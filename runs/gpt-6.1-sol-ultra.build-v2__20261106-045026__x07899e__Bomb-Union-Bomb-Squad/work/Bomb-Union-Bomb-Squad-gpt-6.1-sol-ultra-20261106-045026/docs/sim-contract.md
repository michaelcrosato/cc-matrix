# Bomb Union simulation contract v1
Scripts load `src/sim/content.js`, then `src/sim/model.js`. Both use `globalThis.BU` (no modules).

`BU.CONTENT` is an object keyed by `training`, `waterfront`, `relay`, `central`. Each definition has id, title, subtitle, brief, theme, digits, boardCount, duration, intro, taunts, success, failure, mechanics. `BU.GLYPHS` is ten arrays of twenty 0/1 cells (4 columns x 5 rows). `BU.DEFAULTS` holds finite live tuning.

`BU.Sim.create(caseId='waterfront', seed=1, party=1, tuning={})` returns a JSON-safe mutable authoritative state. Party can be count 1–4 or array of seat IDs. State has `caseId, seed, party, seats, duration, remaining, elapsed, revision, status` (`active`, `won`, `lost`), `cause, code` (array digits; dev/tests only), `evidence` (one array of 20 values -1 unknown, 0 dark, 1 lit per digit), `boards`, `events` (bounded newest accepted events with monotonic `id`, `type`, optional board/component and text), `metrics`, `proposal`, `tuning`, `modified`, `assisted`, and eventual `result`.

Each board: `id` (B1...), `name`, `digit` (zero based), `mask` (reward cell indices), `rule` (`jumper`, `shape`, `color`), `ruleKnown` (boolean), `example` (source/replacement shape/color/pattern), `components`, `order` (required component IDs), `step`, `spares`, `held` (spare ID or null), `claim` (seat ID or null), `heat` (0–100+), `fire`, `recovery` ({component,terminal,remaining} or null), `hold` ({seat,tool,component,terminal,duration} or null), `complete`, `revision`. `components` have `id` C1..., `x,y` in world units around board origin, `shape` (`resistor`, `capacitor`, `chip`), `color` (`amber`, `coral`, `cyan`), `pattern`, `kind` (`jumper`, `replace`), `cuts` pair booleans, `removed`, `part` (spare ID or null), `joints` pair booleans, `done`. Terminal anchors are (x-18,y),(x+18,y). Native workspace may transform this origin freely. Spares: `id` S1..., shape, color, pattern, jumper boolean, available boolean. Each component has exactly one compatible spare; reusable after wrong installation/removal/drop. Stock never destroyed.

`BU.Sim.command(state, seat, cmd)` mutates only authority, returns `{ok,reason,event}`. cmd `{type, board?, component?, terminal?, spare?, id?, caseId?, expectedRevision?}`. Optional `expectedRevision` checks board revision (or global for no board); an `id` deduplicates. Action types:
- `claim`, `release`: board. Claim is atomic, one owned board per seat; claiming new board releases old claim and cancels hold without clearing damage/fire. `release` preserves all repair state.
- `cut`: board, component, terminal 0/1. Both leads required. Off-order cut opens recovery; further cuts rejected while it is pending.
- `grip`: board, component. Removes original after both cuts, or wrong replacement after its leads cut (wrong replacement initially unsoldered and immediately removable). Returns any installed spare to stock. Original is automatically salvaged, so no stranded junk-handling state.
- `pick`: board, spare. Pliers pick available spare. Drop current held spare first.
- `place`: board, component. Places held spare in empty current socket. Wrong part is installed, fails continuity, remains visibly removable. Rule compatibility checked without consuming stock.
- `drop`: board. Returns held spare safely to stock.
- `test`: board, component (defaults current), spare (defaults held). Costs default 2 fuse seconds and discovers fixed board rule; emits PASS/FAIL text, never consumes spare. Can test from tray or while held.
- `begin`: board, tool=`solder` or `extinguish`, component, terminal. Solder on a cut wrong joint repairs recovery; otherwise on installed correct current socket. `end`: board. Solder release succeeds only within safe band [tuning.solderMin, tuning.solderMax]. Excess hold heats/fire. Extinguish release succeeds after tuning.extinguishTime. `cancel`: board clears active hold, no free repair. Holds auto-expire by tuning.maxHold; client loss calls cancel/release.
- `propose`: code array. Requires two completed boards (one training); starts cooperative five-second vote (proposal has a stable unique `id`); proposing counts yes. Solo immediately resolves (the UI must deliberately confirm before sending this). `vote`: accept boolean. Any veto cancels; unanimous immediate resolution; strict majority/no veto after deadline resolves; otherwise cancels.
- `leave`: removes seat, releases claims/holds; cancels proposer departure; adjusts eligible vote seats. Party workload/fuse remains locked.
- `tune`: values object. Clamps known tuning keys, cancels holds coherently, marks modified. Transport must prohibit in live Hub. `dev`: operation (`fire`,`fault`,`reveal`,`solve`,`fuse`) and board/value. Marks modified.

`BU.Sim.advance(state, dt)` advances authoritative simulation time; caller implements solo pause and online wall-clock policy. Cools offscreen boards, maintains established fire, evaluates recovery penalties, expires bounded holds/proposals, and resolves fuse exactly once. `BU.Sim.instruction(state,boardId)` returns persistent text describing the next legal repair step. `BU.Sim.candidates(cells)` returns compatible digits. `BU.Sim.compatible(board,component,spare)` returns bool. `BU.Sim.board(state,id)` / `component(board,id)` lookup. `BU.Sim.snapshot(state)` JSON clone; `restore(snapshot)` validates version/schema. `BU.Sim.validateContent()` returns errors array. `validateTemplate(template)` returns structural/stock errors array; `validateScratch(template,seed)` additionally requires the template's evidence to uniquely identify the scratch seed's digit; `exportTemplate(board)` yields versioned JSON authoring object; `createScratch(template,seed)` validates and returns isolated state (modified). `BU.Sim.nextAction(state,boardId)` returns {type,...} ordinary operation for test/attract support only (not production auto-play).
