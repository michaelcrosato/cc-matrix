# Controls and clock policy

All players use the same native Shell screens. Mouse hover moves focus; clicking applies to the hovered target. WASD/arrows or the left stick/D-pad snap between targets. Space/Enter or Cross applies the chosen tool; hold and release the iron inside the green band. 1–4 select cutters, pliers, iron, foam; wheel or L1/R1 cycles. E/Square tests a spare. R/Triangle repeats the current work order. Tab/R2 opens shared evidence; Escape/Options opens the native pause menu. Right click/Circle drops safely or goes back. Shift/L2 expands precision snapping.

Button symbols default to PlayStation and can be changed to Xbox in native Controls. All custom actions participate in native rebinding, and their labels follow the last active device. Text size, reduced motion/flashes, independent audio buses, candidate assistance, touch assistance, and settings reset are available.

Touch uses direct target taps, automatic legal-tool selection, a single safe contextual action, and threshold-assisted solder/foam. It labels assisted results. The PCB expands to portrait width; no permanent virtual-button wall is needed. Actual phone/tablet hardware and iOS are unverified; tests emulate touch in Playwright.

Solo native pause freezes fuse, heat, recovery and held work. A native input hook cancels in-progress holds on physical pause and handles custom sound lifecycle. Online menus are local: the host's wall/Hub clock continues, as the persistent fuse label says. Leaving evidence or a repair never clears its fire/recovery or fixes its joints. Established fire requires foam.

Local settings/progress are versioned and recover safely from unavailable or corrupted storage. Attract mode uses a separate device and never writes ordinary records or starts a room. Its wake input is consumed.

The native Shell also provides a live Text size slider. The active fuse stays visible above evidence/code/help/settings overlays. Its label distinguishes a frozen solo pause from an online menu where the authoritative fuse continues.
