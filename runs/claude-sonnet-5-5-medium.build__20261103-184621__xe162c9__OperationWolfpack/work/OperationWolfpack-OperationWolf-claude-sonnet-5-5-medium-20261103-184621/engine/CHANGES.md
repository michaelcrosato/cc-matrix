# Engine changes (my-3D2dge v0.85.2 handoff, edited for Operation Wolfpack)

1. `my-3d2dge.js`, the standard `glyphs` setting (Controller group): default changed from `'auto'` to `'playstation'`, and the options cut
   to PlayStation and Xbox only (they were Auto, Xbox, PlayStation, Nintendo, Positions). The game is built for a DualSense on a TV and
   the task asks for PlayStation glyphs by default with an Xbox option. The game also mirrors the setting in Settings > Game as
   "Button symbols".

Nothing else in the engine was edited. The game uses the Mode7 and Arcade modules that are already inside `my-3d2dge.js`.
